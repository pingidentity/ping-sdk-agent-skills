# Vanilla JS OIDC Templates (placeholder)

OIDC centralized login templates for Vanilla JS are not yet available.

When this framework is activated in the Framework Registry, add templates here following the same pattern as `assets/react/`:
- `.env.template`
- `callback.html.template`
- `app.js.template`
- `login.js.template`
- `home.js.template`
