# Angular OIDC Templates (placeholder)

OIDC centralized login templates for Angular are not yet available.

When this framework is activated in the Framework Registry, add templates here following the same pattern as `assets/react/`:
- `.env.ts.template` (or `environment.ts.template`)
- `callback.component.ts.template`
- `app.component.ts.template`
- `login.component.ts.template`
- `home.component.ts.template`
